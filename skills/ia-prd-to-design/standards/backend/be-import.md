# 数据导入规范（TDD 第3章 §3.7）

## 3.7 数据导入规范

仅当 PRD 包含批量导入、Excel 导入或模板化数据初始化功能时输出。

### 导入模式选型

| 场景 | 模式 | 说明 |
|------|------|------|
| 数据量 < 1000 条、字段少、实时反馈 | 同步导入 | 上传后立即解析并落库，接口同步返回结果 |
| 数据量 ≥ 1000 条、复杂校验、耗时处理 | 异步导入 | 提交任务 → 异步解析校验 → 分批落库 → 查询进度/下载结果 |
| 超大文件 / 跨系统一致性要求高 | 本地解析+异步落库 | 前端/网关先落临时文件，后台任务异步消费 |

### Jalor 导入 API 规范

Excel 批量导入使用 **Jalor 框架内置 Servlet 接口**，路径不走 `/uiapi/` 前缀；设计文档中须按下列固定契约描述，不得自行发明 REST 风格导入路径。

> 实现细节（Provider 类、XML 配置、临时表机制）见 Excel 导入二方件规范；权限码与 `config-permission` 中 `import` 操作对齐。

### 导入 API

| 操作 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 上传导入 | POST | `/servlet/upload?ulType=ExcelImport&excelType={excelId}` | 上传 Excel 文件并触发导入（同步或异步由后台判定） |
| 查询进度 | GET | `/uiapi/import/tasks/{id}` | 异步导入时查询任务状态、成功/失败数 |
| 下载结果 | GET | `/uiapi/import/tasks/{id}/result` | 下载校验失败明细或导入结果文件 |

### 模板规范

- 模板文件与业务对象一一对应，文件名：`{业务对象}_导入模板.xlsx`
- 首行为字段中文名，第二行为字段英文名（可选），数据从第三行开始
- 必填列用 `*` 标注；下拉枚举列在模板中提供可选值
- 禁止合并单元格；Sheet 名固定为 `Sheet1`

### 内存与性能约束

- 禁止一次性把全量 Excel 数据加载进内存
- 使用流式读取（EasyExcel / POI Event API），每批处理 500-1000 条
- 大文件（> 10MB）必须走异步导入，先存临时文件或 OSS

### 数据校验与错误处理

- 模板级校验：列名/列数匹配、必填项缺失、字段格式（日期/数字/枚举）
- 业务级校验：重复数据、外键存在性、业务规则冲突
- 错误回写：生成结果文件，逐行标注错误原因；失败行可单独修正后重新导入
- 部分成功策略：默认开启；成功行落库，失败行进入结果文件

### 幂等与去重

- 同一文件重复上传须识别（文件名 + MD5 或任务去重键）
- 业务主键重复时：支持“跳过/覆盖/报错”三种策略，按 PRD 明确选择

### 临时表与结果表

| 表类型 | 用途 | 生命周期 |
|--------|------|----------|
| 临时表 | 暂存原始解析数据，便于批量校验和去重 | 任务完成后清理 |
| 结果表 | 记录每条记录导入状态、错误码、错误信息 | 保留 30 天 |
| 任务表 | 记录导入任务状态、文件路径、操作人、进度 | 长期保留 |

### 权限与审计

- 导入操作使用 `@JalorOperation(operationCode = RequestConstants.IMPORT)` 校验
- 记录操作日志：操作人、时间、文件名、成功/失败数、任务 ID

### 异步导入流程（数据量 ≥ 1000 或文件 > 10MB 时）

| 步骤 | 接口/方法 | 说明 |
|------|---------|------|
| 1. 提交任务 | `POST /servlet/upload?ulType=ExcelImport&excelType={excelId}` | 接收文件，创建任务记录（状态 PENDING），返回 taskId |
| 2. 解析校验 | `ImportTask.parse()` | 流式读取 Excel，逐批校验，写入临时表 |
| 3. 去重落库 | `ImportTask.persist()` | 按去重键去重，成功数据落业务表 |
| 4. 生成结果 | `ImportResult.generate()` | 失败行写入结果文件，更新任务状态 DONE/PARTIAL |
| 5. 查询/下载 | `GET /uiapi/import/tasks/{id}`、`/result` | 前端轮询进度，完成后下载结果文件 |

### 错误码/异常场景

| 错误码 | HTTP 状态码 | 说明 | 动作 |
|--------|------------|------|------|
| `APP-{MOD}-BIZ-001` | 400 | 模板列数/列名不匹配 | ✨ |
| `APP-{MOD}-BIZ-002` | 400 | 必填字段缺失 | ✨ |
| `APP-{MOD}-BIZ-003` | 400 | 字段格式错误（日期/数字/枚举） | ✨ |
| `APP-{MOD}-BIZ-004` | 409 | 业务主键重复 | ✨ |
| `APP-{MOD}-BIZ-005` | 400 | 外键关联数据不存在 | ✨ |

### 实现依赖

- 依赖接口：`POST /servlet/upload?ulType=ExcelImport&excelType={excelId}` - 文件上传与导入触发
- 依赖服务：`{ImportTaskService}` - 异步解析、校验、落库
- 依赖服务：`{ImportResultService}` - 结果文件生成与下载
- 依赖表：`{临时表}`、`{结果表}`、`{任务表}`
