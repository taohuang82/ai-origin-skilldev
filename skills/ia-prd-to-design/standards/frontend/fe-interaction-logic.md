# fe-interaction-logic

**规范分段**：`fe-interaction-logic`（已整合原 `fe-state`，`fe-state` 作为 alias）

## 规范条文

### 状态管理

#### 状态存放

| 条件 | 位置 |
| ---- | ---- |
| 单组件内 | `ref` / `reactive`（自 `vue-demi`） |
| 同页多组件 | 父 State + Props |
| 跨页或持久 | Pinia 等 Store |
| 可分享/回退保留 | URL Query（一级路径不变） |

Store 命名惯例：`loading`、`submitting`；离开页面按需 reset（按工程惯例）。

#### 状态模型职责

- 本分段负责状态模型定义（变量、类型、存放位置、初始化、重置）。
- 交互链路分段负责用户操作链路与反馈闭环。
- 两分段不得重复输出同一大段内容。

### 反馈与表单

- 操作须有即时反馈；长耗时操作须有 Loading。
- 禁止原生 `alert` / `confirm` / `prompt`；二次确认与提示使用脚手架提供的对话框 / Message。
- 弹窗 / 抽屉不占路由，在父页面用 visibility 控制显隐。
- 表单须说明必填标识、校验时机、提交失败反馈和脏数据离开提示。

### 前后端边界

- 前端承担展示与体验层校验，不替代后端强校验。

### 关键操作覆盖

每个关键操作包含：触发方式、前置条件、有序步骤、参数组装、成功反馈、失败反馈。
