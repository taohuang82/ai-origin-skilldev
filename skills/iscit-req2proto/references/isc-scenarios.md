# 供应链典型场景速查

当用户描述需求时，可参考以下场景推断页面所需的字段、流程和交互模式。

## 交易类 (tp) 场景

### 1. 采购订单管理
- 核心字段：订单号、供应商、物料编码、物料名称、数量、单价、金额、交货日期、状态
- 典型状态：草稿 → 待审批 → 已审批 → 已下发 → 部分到货 → 已完成 → 已关闭
- 关键交互：新建、编辑、提交审批、审批通过/驳回、导出

### 2. 销售订单管理
- 核心字段：订单号、客户、产品、数量、单价、金额、交货日期、订单状态
- 典型状态：待确认 → 已确认 → 生产中 → 已发货 → 已签收
- 关键交互：创建、确认、排产、发货、签收确认

### 3. 库存管理
- 核心字段：物料编码、物料名称、仓库、库位、批次号、可用数量、冻结数量、安全库存
- 典型操作：入库、出库、调拨、盘点、冻结/解冻
- 关键交互：扫码入库、库存查询、库存预警、批次追溯

### 4. 物流运输管理
- 核心字段：运单号、承运商、起始地、目的地、运输方式、预计到达、实际到达、状态
- 典型状态：待提货 → 运输中 → 已到达 → 已签收 → 异常
- 关键交互：创建运单、跟踪、签收、异常上报

### 5. 供应商管理
- 核心字段：供应商编码、名称、联系人、分类、等级、认证状态、合作状态
- 典型操作：准入、评估、分级、淘汰
- 关键交互：供应商注册、资质审核、绩效评分

### 6. 需求计划
- 核心字段：计划编号、产品、预测数量、计划周期、需求类型、优先级
- 典型操作：创建计划、调整、审批、下发
- 关键交互：预测录入、计划对比、版本管理

### 7. 质量检验
- 核心字段：检验单号、物料、批次、检验类型、检验结果、不良数量、判定
- 典型状态：待检 → 检验中 → 合格 → 不合格 → 让步接收
- 关键交互：来料检验、过程检验、成品检验、不合格品处理

## 分析类 (ap) 场景

### 8. 全球运输监控大屏
- KPI 指标：在途订单数、准时率、异常率、运输成本
- 可视化：世界地图运输路线、实时状态标记
- 辅助图表：承运商排行、时效趋势、异常类型分布

### 9. 库存分析看板
- KPI 指标：库存总额、周转率、呆滞率、缺货率
- 可视化：库存结构饼图、周转趋势折线图
- 辅助图表：TOP 呆滞物料、各仓库库存对比、安全库存预警

### 10. 供应商绩效看板
- KPI 指标：合格率、准时交货率、响应时效、综合评分
- 可视化：供应商等级分布、月度趋势
- 辅助图表：TOP/BOTTOM 供应商排行、各品类合格率对比

### 11. 采购分析看板
- KPI 指标：采购总额、节省金额、供应商数量、订单数量
- 可视化：采购金额趋势、品类占比
- 辅助图表：月度采购对比、供应商集中度、价格波动

### 12. 生产监控大屏
- KPI 指标：计划完成率、设备利用率、良品率、产能利用率
- 可视化：产线状态实时图、产量趋势
- 辅助图表：各产线对比、设备状态分布、异常告警列表

## 推断规则

当用户描述不够详细时，按以下规则补全：

1. **未指定字段**：参考上方对应场景的核心字段，选择最常用的 5-8 个
2. **未指定状态流转**：使用上方对应场景的典型状态
3. **未指定操作按钮**：默认提供「新增」「编辑」「删除」「搜索」「导出」
4. **未指定筛选条件**：取核心字段的前 3-4 个作为筛选项
5. **分析类未指定图表**：默认提供 3-4 个 KPI 卡片 + 1 个主图表 + 2 个辅助图表
6. **分析类数据**：使用合理的模拟数据，数值范围符合业务实际
