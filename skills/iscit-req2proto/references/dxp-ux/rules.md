# 可验收 UX 规则（内置于 iscit-req2proto）

> 来源：ISC IT / DXP UX 规范沉淀；生成 HTML 原型时与 [tinyvue-spec.md](../tinyvue-spec.md) 配合使用。  
> 目的：把规范描述转成“生成 HTML+CSS 时可直接验收”的硬规则。

## A. 页面与栅格

- [ ] **24 栅格**：内容区按 24 列栅格布局（见原始规范 `栅格 Grid.md` 意图）
- [ ] **gutter=16px**
- [ ] **offset=24px**：页面主内容左右内边距为 24px
- [ ] **画板基准 1920**
- [ ] **模块间距节律**：模块间优先 24px；模块内 8/16px
- [ ] **<1280 行为**：T 型布局下左侧固定，内容溢出出滚动

## B. 按钮（Button）

- [ ] **一个按钮区最多 1 个主按钮**
- [ ] **主按钮颜色**：背景 `#191919`，文字 `#FFFFFF`
- [ ] **状态齐全**：hover / active / disabled 必须存在
- [ ] **按钮顺序**：确认类动作“主要按钮在右侧”，取消等反向在左侧
- [ ] **按钮溢出**：同区域按钮过多（建议最多 3），多余收纳到“更多/…”

## C. 弹窗（Modal）

- [ ] **宽度档位**：400/550/700/900；最小 400 最大 900
- [ ] **遮罩**：`#000000` 透明度 30%
- [ ] **滚动**：仅内容区滚动，标题区/操作区固定
- [ ] **位置策略**：距浏览器顶部 100px；距底部不足 100px 时内容区滚动
- [ ] **禁止双层弹窗**
- [ ] **拖动**：弹窗位置可拖动（纯 HTML/CSS 时可预留 `.ux-modal__title` 作为拖拽手柄挂载点）

## D. 抽屉（Drawer）

- [ ] **宽度档位**：500/600/700/960；最小 500 最大 1000
- [ ] **滚动**：仅内容区滚动，标题区/操作区固定
- [ ] **层级限制**：最多双层抽屉
- [ ] **双层规则**：第二层比第一层窄 14px

## E. 表格（Table）

- [ ] **默认能力**：过滤/分页/排序默认提供
- [ ] **空值显示**：空值 `--`；未知 `Unknown`
- [ ] **表头高度**：单层 40px；双层 64px
- [ ] **操作列**：固定操作列默认开启；最多显示 3 个操作，其余收纳到“更多”
- [ ] **列宽下限**：列宽最小 72px
- [ ] **对齐**：文本/时间左对齐；数字/金额右对齐

## F. 文案（Copywriting）

- [ ] **中文优先**：非通用英文术语不得直接出现在界面
- [ ] **缩写规则**：缩写 + 中文全称（或悬浮提示）且全程一致
- [ ] **页面不加冒号**：统一不加冒号（特殊场景例外：下拉选项、表格字段信息等）
- [ ] **中英文空格**：英文、数字、单位等按规则添加半角空格
- [ ] **标点半角/全角**：中文环境默认全角；特定场景半角
