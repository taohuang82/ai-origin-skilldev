# 交易类（TP）列表页 UX 规则（tp-ux）

> 与 **DXP 四层列表**（`references/dxp-ux/examples/list-page`）并列：TP 典型企业应用为 **「查询条件区 + 表格」**，表格 **操作区在左侧**、与 DXP 常见「操作列在右」不同。  
> 弹窗、抽屉、栅格间距等 **仍可与** `references/dxp-ux/rules.md` **对齐**；本节仅规定 **TP 列表页专有** 的布局与列序。

## 1. 查询条件区（表单）

- [ ] **独立区块**：与表格主数据区分；整块外层可用 `section` + `aria-label="查询条件"`。
- [ ] **页签式标题栏（可折叠）**：查询区 **顶部左侧** 为 **「查询条件」** 文案；其 **右侧 16px** 处为 **chevron**；浅蓝背景 **#E6F4FF** 或与产品统一的浅蓝。**展开**时箭头 **朝上**，**收起**后箭头 **朝下**；点击 **文案+chevron 区域** 切换 **下方表单栅格 + 查询/重置** 的显示/隐藏。实现可用 `<details>`/`<summary>` 或按钮 + `aria-expanded` + 脚本，行为一致即可。
- [ ] **（可选）标题栏右侧工具**：与「查询条件+chevron」**同一行最右侧** 可放置固定、布局、设置等 **icon 按钮**；点击 **不得** 触发展开/收起（`stopPropagation` / 独立 DOM）。与 **chevron** 的 16px 间距规则不冲突：左侧组为「文案 + chevron」，右侧组为工具图标。
- [ ] **多列栅格**：筛选项以 **2～5 列** 栅格排布（字段多时可用 5 列，参考 `multi-tab-tp-page`）；标签在上、控件在下或与控件同一行，全页风格一致。
- [ ] **主操作**：「查询」为区块内主按钮；「重置」为次按钮（描边/白底）。按钮组可 **水平居中** 或 **靠右对齐**（管理台常见，见 `multi-tab-tp-page`）。
- [ ] **复杂筛选**：日期区间、带浏览按钮的选人等放在查询区内，**不把**列设置类 icon 强行塞进表头代替查询区（与 DXP「设置须在筛选行」精神一致，但 TP 查询区是 **表单栅格** 而非单行综合搜索）。

## 2. 表格上方轻量操作条

- [ ] **位置**：紧挨表体 **上方** 单独一行（如仅「导出」），**不作为** DXP list-page 的整页顶栏大工具条替代；批量操作多时可扩展为左对齐按钮组。

## 3. 表格列顺序（强制，与 DXP 样例差异）

自 **左向右** 固定前三列语义，第四列起为业务字段：

| 顺序 | 列 | 说明 |
|------|-----|------|
| **1** | **序号** | 当前页序号 `1…n`；表头「序号」；可与分页联动展示。 |
| **2** | **选择** | 多选为 `checkbox` 列（表头可全选）；单选为 `radio` 列（表头无全选或仅占位）。需求未要求选择时可省略本列，但 **不得** 把操作列挪到选择列之前。 |
| **3** | **操作** | 编辑、删除、查看等链接/文字按钮；超过 3 个操作收纳「更多」。**固定靠近左侧**（文本左对齐），与 DXP 示例中操作列在 **最右侧** 不同。 |
| **4+** | **业务列** | 单号、状态、时间等业务数据；主单号等可链样式 `ux-linkText`。 |

- [ ] **表头高度、空值 `--`**：与 `references/dxp-ux/rules.md` 表格章节一致时可复用。
- [ ] **横向滚动**：列多时在 `ux-tableWrap` 内滚动；必要时序号/选择/操作三列可做 **左侧冻结**（原型可用 `position: sticky` 简化）。

## 4. 分页

- [ ] 表体 **下方** 独立分页区（条数摘要 + 每页条数 + 页码），不得把分页塞进表头。

## 5. 左侧导航 + 主区（电子流 / 管理台壳）

适用于 **电子流审批**、合同/订单 **管理台** 等「整页 = 左侧菜单 + 右侧业务」形态（实现侧常对应 `el-container` + `el-aside` + `el-main` 或等价布局）。

- [ ] **壳层**：`aside.tp-navMenu`（或语义 `nav`）固定 **约 220～260px** 宽（或大屏下可折叠，原型可省略）；`main.tp-main` 占满剩余宽度并 **单独滚动**（避免整页与侧栏一起滚丢导航）。
- [ ] **nav-menu 顶部筛选**：提供窄搜索框，占位 **「请输入内容进行筛选」**（或产品统一文案），用于过滤菜单项。
- [ ] **菜单层级**：一级分组可展开/收起；**当前路由** 项使用 **浅蓝底 + 主色字**（与表格头浅蓝可同一色系，见 `e-flow-approval-page`）。
- [ ] **主区内**：仍遵守 **第 1～4 节**（查询条件区、表上轻操作、**列序**、分页）；不在侧栏放置表格分页。

## 6. 主区顶部多 Tab（业务视图切换）

适用于 **同一功能域下多子视图**（如多种「协同查询」、多分析视角），**不是**查询条件折叠条上的 Tab。

- [ ] **位置**：位于 **主内容区最顶**（页标题之下、第一个业务卡片之上），**横向** 排列；支持 **横向滚动**（`overflow-x: auto`），避免窄屏换行破坏结构。
- [ ] **交互**：**有且仅有一个** `aria-selected="true"` 的页签；切换时 **只切换** 下方 `tabpanel` 内容，**不卸载**公共壳（若有侧栏 nav 则侧栏不动）。
- [ ] **选中态**：当前页签 **主色字 + 下划线**（或与产品统一的 Tab 选中样式），未选中为灰字。
- [ ] **无障碍**：使用 `role="tablist"` / `role="tab"` / `role="tabpanel"`，并保持 `aria-controls` / `aria-labelledby` 对应关系。
- [ ] **与内容类型**：某一 Tab 可为 **表单+表格**（遵守第 1～4 节）；另一 Tab 可为 **KPI + 图表** 的分析页（不要求表格左三列）；其余 Tab 可用 **占位文案** 说明待建设。

## 7. 与 DXP / TinyVue 的关系

- **主色**：TP 查询区主按钮在原型中可采用 **信息蓝**（如 `#1677FF`，与 TinyVue 交易页常见主按钮一致）；页面级全局主 CTA 若与 `ux-tokens.json` 冲突，在交付说明中标注「TP 列表查询区以本 tp-ux 规则为准」。
- **类名**：可继续复用 `ux-*` / `tv-*` 与 `components.md` 中的控件语义，仅 **列顺序与分区**（及 **侧栏壳**、**主区多 Tab**）按 tp-ux 执行。
