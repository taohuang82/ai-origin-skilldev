# 设计文档专用去噪规则字典

> 本文档定义各格式设计文档的去噪规则。清理流程见 [workflows/cleanup.md](../workflows/cleanup.md)。

设计文档相比通用 Office 文档，有大量模板残留、修订标记、装饰元素。以下规则按格式分组，遵循**保守原则**：不确定时保留，宁可漏删不可误删。

## 通用规则（所有格式）

| 噪声类型 | 识别特征 | 处理 |
|---------|---------|------|
| 水印 | 每页重复出现的半透明文本 | 删除 |
| 页眉页脚 | 每页重复，含页码/公司名/文档编号 | 删除（保留正文） |
| 空段落 | 连续 2+ 个空行 | 合并为 1 个 |
| 内容控件 | `<w:sdt>` 包裹的占位符 | 删除占位符，保留实际内容 |
| 目录字段 | TOC 字段生成的页码目录 | 删除自动生成的 TOC，保留手动标题 |
| 不可见字符 | 零宽空格、BOM、制表符混用 | 清理为标准空格 |

## Word（DOCX）专项

| 噪声类型 | 识别方法 | 处理 |
|---------|---------|------|
| **修订标记** | `<w:ins>`/`<w:del>` XML 元素 | 接受所有修订，输出最终态 |
| **批注** | `<w:commentReference>` | 删除批注标记及批注内容 |
| **样式校准** | 样式名 `Heading X` 与实际字号不符 | 以样式名为准重建标题层级 |
| **TOC 字段** | `w:fldSimple` 或 `w:instrText` 含 TOC | 删除自动 TOC |
| **脚注/尾注** | `footnoteReference` | 转为行内括号注释或删除（按配置） |

### 修订处理伪代码

```python
def process_revisions(docx_xml):
    # 接受所有 <w:ins>：保留插入内容，删除标记
    xml = remove_tags_keep_content(docx_xml, 'w:ins')
    # 拒绝所有 <w:del>：删除删除标记及内容
    xml = remove_tags_and_content(xml, 'w:del')
    # 删除批注引用
    xml = remove_tags(xml, 'w:commentReference')
    return xml
```

## PowerPoint（PPTX）专项

| 噪声类型 | 识别方法 | 处理 |
|---------|---------|------|
| **母版占位符** | slideMaster 中的占位符文本（"单击此处添加标题"） | 删除 |
| **讲者备注** | notesSlide 中的文本 | 分离为独立"备注"段落（按配置保留或删除） |
| **SmartArt 退化** | SmartArt 仅剩文字骨架 | 提取为图片 + 5维描述 |
| **动画指示** | transition/animation 元素 | 忽略（不影响内容） |
| **隐藏幻灯片** | `show=false` 的 slide | 按配置跳过或保留 |

## Excel（XLSX）专项

| 噪声类型 | 识别方法 | 处理 |
|---------|---------|------|
| **隐藏 sheet** | `sheetState="hidden"` | 按配置跳过或转为附录 |
| **合并单元格** | `mergeCell` | 还原为文字说明（"合并：A1:C1"） |
| **公式 vs 值** | 单元格含 `f`（公式）和 `v`（值） | 默认取值，公式记录到 JSON 映射 |
| **空行/空列** | 整行/整列无数据 | 删除（保留表头） |
| **条件格式** | conditionalFormatting | 忽略（不影响数据） |
| **图表** | drawing/chart | 提取为图片 + 5维描述 |

## PDF 专项

| 噪声类型 | 识别方法 | 处理 |
|---------|---------|------|
| **扫描页空白** | OCR 后无文本的页 | 跳过 |
| **书签冗余** | PDF outline 与标题重复 | 保留标题，删除书签 |
| **表单字段** | AcroForm | 提取填入值，删除空字段 |
