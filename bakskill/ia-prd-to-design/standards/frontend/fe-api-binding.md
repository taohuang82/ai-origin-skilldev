# 接口与数据规范（§4.5 · `fe-api-data`）

对应要素：**接口与数据**。声明页面依赖 `backend-api.md` 的接口及前后端数据在页面的映射规则。

---

## 项目框架约束（重要）：服务请求方式

- **统一**：在实现侧使用 **`const service = useService()`**（来源：**`@turboui/meta-template`**，以工程锁定版本为准）。
- **调用**：**`service.network.get(url, { params })`** / **`service.network.post(url, data)`**（路径与 `backend-api.md` 一致）。
- **禁止**：方案正文禁止堆砌完整调用源码；允许用条目说明「触发场景 + URL + 方法 + get/post」。
- **禁止**：绕过脚手架封装随意使用裸 **`axios` / `fetch`**（除非脚手架文档明确允许的例外，须在「编码约束」中声明）。

---

## 编写要求

- **仅引用已定义的接口**，路径与方法与 `backend-api.md` 一致，禁止自创冲突契约。
- **并发**：防重复提交；页面离开时按需取消请求；无依赖可并行，有依赖须写明顺序。
- **入参**：标明来源（表单 / URL Query / Store / 上游响应 / 计算）。
- **出参**：分页字段路径、枚举展示、脱敏规则须在页面级说清。
- 展示格式化：`computed` / utils（Composition API）；提交前组装放在约定的 composable 或服务层（按工程惯例）。
